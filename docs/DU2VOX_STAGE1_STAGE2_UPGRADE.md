# DU2Vox Stage1/Stage2 Upgrade

## 1. Motivation

CQR failure attribution showed that `rolesplit + residual_scale=1.0` recovers much of the old CQR gap, but common-domain Dice remains around `0.6429`. The next main line is no longer ROI-only tuning; ROI-only is kept as historical context only.

The new route is:

```text
Balanced Stage1 support initialization
+ CQR confidence-stratified query construction
+ support-aware multiview refinement
```

## 2. Stage1 Balanced Training

The Stage1 training path now supports clearer support-oriented training and checkpoint selection:

- `configs/stage1/uniform_1000_20k_balanced_dice05.yaml` uses sigmoid activation, `support` loss, `tversky_alpha=0.3`, `tversky_beta=0.7`, BCE, and primary `dice_bin_0.5` checkpointing.
- `scripts/train_stage1.py` saves `best_dice03.pth`, `best_dice05.pth`, `best_softdice.pth`, `best_val_loss.pth`, `latest.pth`, and `best.pth` according to `checkpoint.primary_metric`.
- `du2vox/evaluation/metrics.py` reports explicit `pred_threshold` versus `gt_threshold` metrics such as `dice_pred05_gt05`, `precision_pred05_gt05`, and `recall_pred05_gt05`.
- `data.use_visible_mask` defaults to `false` so training and inference use the same full-surface forward matrix unless explicitly configured otherwise.

Audit command:

```bash
uv run python scripts/audit_stage1_checkpoint.py \
  --config configs/stage1/uniform_1000_20k_balanced_dice05.yaml \
  --checkpoint runs/stage1_uniform_1000_20k_balanced_dice05/checkpoints/best_dice05.pth \
  --split val \
  --max_samples 200 \
  --out_csv results/stage1_balanced_dice05_audit.csv \
  --out_json results/stage1_balanced_dice05_audit.json
```

The audit currently reports mesh Dice/precision/recall, prediction statistics, ROI tet ratio, and GT ROI coverage over threshold/dilation sweeps.

## 3. Stage2 Support-Head

`CQRResidualINR` now has an optional support head:

- `support_head: true` adds `support_logit` and `support_prob` outputs.
- `output_mode: residual | support | hybrid` controls which prediction is used for Dice/evaluation.
- `hybrid_alpha` blends `support_prob` with clamped residual prediction in hybrid mode.

The new Stage2 loss is `hybrid_support`:

- MSE keeps continuous reconstruction aligned with GT intensity.
- BCE optimizes the support boundary through `support_logit`.
- Soft Dice directly targets support overlap.

Main config:

```text
configs/stage2/cqr_stage1_balanced_dice05_rolesplit_supporthead_multiview.yaml
```

## 5. Conclusion

This upgrade changes the main line from CQR patching to support-aware reconstruction. The success criteria are:

- Stage1 improves Dice@0.5 and precision@0.5 without collapsing recall.
- Balanced Stage1 bridge keeps ROI coverage high while reducing ROI tet ratio.
- Stage2 support-head improves common-domain Dice over the current best CQR result, `S2=0.6429` and `Delta=+0.0378`.
